# 가정 및 OEM 질의 목록

| 항목 | 내용 |
|------|------|
| 문서 ID | DOC-ASM-001 |
| 버전 | 0.2 (Iter-0, 1차 리뷰 반려 조치본) |
| 상태 | 초안 (재리뷰 대기) |

OEM-SWR-001(Rev 1.0)의 모호·충돌 항목은 사용자가 승인한 제안안으로 임시 진행한다.
사용자는 이 프로젝트에서 OEM 수용 역할을 대행하며(2026-11-27 승인), 아래 가정과 편차는 **사용자 대행 승인** 상태다. 실제 OEM의 확인은 아니다.
OEM이 다르게 확정하면 해당 요구사항과 이후 산출물을 재검증한다.

상태 체계: 가정(승인됨) = 사용자 승인, OEM 확인 대기. 확인 = 사실 확인만 필요하며 요구 영향 없음.
