## 3. 교차 점검 결과

- **6.3 ↔ SAFETY-REQ**: 순위 1~9와 SSR 참조가 일치함. 순위 4(SSR-011)는 순위 5~10 hold이며 순위 6 접근위험 LOCK은 SSR-011이 예외로 지정함. 순위 5(SSR-010)는 순위 1~3과 SSR-004 예외. 순위 3(ignition off)은 순위 4~10 우선. SSR-013이 순위 1~3의 FAULT/DEGRADED 적용을 정함. 충돌 없음.
  - 단, 순위 7 ISOFIX와 순위 9 자동 잠금은 순위 4·5 hold의 대상이 되는데, 이것이 SRS-F-015의 요구와 충돌함 (R3-02).
- **6.3 ↔ 상태 결정(SSR-015)**: 순위 4는 FAULT 상태, 순위 5는 DEGRADED 상태에서만 활성이므로 두 규칙은 동시에 활성일 수 없음. 순위 3(OFF 상태)과 순위 5도 동시에 활성일 수 없음 (R3-01).
- **ASSUMPTIONS ↔ SRS/SAFETY**: A-01(순위 순서)은 6.3과 일치. A-02의 문구는 SSR-004/011과 다름 (R3-04). A-03, A-08, A-14, A-16의 본문은 SRS와 일치. 가정이 가리키는 SRS ID 5건이 틀림 (R3-03).
- **ASSUMPTIONS 편차 기록**: 편차 표에 "A-01~A-09, A-13~A-16 가정, 사용자 제안안 승인 (2026-11-27)" 행과 "게이트 수용 주체" 행이 있음. 승인 사실 자체는 코디네이터 지시에 따라 존재 여부만 확인함. ISOFIX·자동 잠금의 hold 억제에 대한 편차 행은 없음 (R3-02).
- **TRACE ↔ SRS**: SRS 31건 모두 TRACE §1에 있음. SSR 15건 모두 TRACE §1에 있음. OEM-SR 4, FR 7, NFR 2, IF 9 모두 TRACE §2에 있고 SRS 상위 열과 일치함. TRACE §3 편차 행이 ASSUMPTIONS와 일치함.

## 5. 확인 사항 (결함 없음)

- 활성 ID 31건(SRS) 및 SSR 15건의 고유성과 번호 연속성 확인. 폐기 ID(SRS-F-005, 006, 008~013, L-001~003)가 본문에 없음 (§8 제외).
- SRS §2의 SSR 참조 목록이 SAFETY-REQ 15건을 모두 포함 (SSR-001~015).
- 6.2 열거형: state(OFF, NORMAL, DEGRADED, FAULT), 경고코드 W-001, reason_code 17개 중 NONE, CMD_APPLIED, INPUT_INVALID, DEGRADED_STALE, OVERRIDE, APPROACH_RISK_SUPPRESSED, ISOFIX_LOCK, AUTO_LOCK, IGNITION_OFF, SENSOR_FAULT, CRASH_CONFIRMED, CRASH_PENDING, FIRE, OVERTEMP, ADULT_PRESENT, CMD_REJECTED_SPEED, APPROACH_RISK_LOCK 모두 사용처가 있음.
- SSR-015 state 결정 규칙과 SSR-014 복귀 규칙이 6.3 주석과 일치.
- A-16 시간축 정의가 6.1 및 SSR-008과 일치.
- 사용자 대행 승인: ASSUMPTIONS 10행과 편차 표, TRACE §3에 기록이 존재함을 확인. 승인 사실 자체는 결함으로 보지 않음.

## 7. 판정 메모

- 중대 결함 R3-02는 아동 보호(ISOFIX)와 접근 시 자동 잠금의 FAULT/DEGRADED 억제에 관한 것이므로 사용자 판단이 필요하다. 억제를 유지하려면 편차로 기록하고 승인을 받는다. 예외로 추가하려면 6.3과 SRS-F-015를 함께 고친다.
- R3-03은 단순 참조 오류이지만 추적성 단절이므로 중대로 분류했다.
- 재리뷰 시 R2-07, R2-08, R2-09 부분 조치와 R3-01~R3-09의 조치 상태를 표로 확인하고, 6.3, SAFETY-REQ, ASSUMPTIONS, TRACE를 함께 교차 점검한다.
