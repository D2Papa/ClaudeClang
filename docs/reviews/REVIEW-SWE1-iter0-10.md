## 3. 교차 점검 (최종)

- **6.3 ↔ F-014, F-016, F-031**: 순위 2 긴급 해제는 입력 TRUE 동안 매 주기이고, 순위 3 OFF는 ignition FALSE 동안 매 주기이며 순위 4~7을 억제한다. 6.3 주석과 일치한다.
- **6.3 ↔ F-030 ↔ F-002**: 순위 6 내부에서 같은 도어의 운전자 lock 명령은 override를 끝내고 LOCK한다 (CMD_APPLIED). 억제 상태(OFF, DEGRADED, FAULT)에서는 명령이 적용되지 않으므로 종료 조건이 아니다. 두 규칙이 일치한다.
- **6.3 ↔ F-004 ↔ SSR-016**: 자동 잠금은 유효 차속 ≥ 3.0 km/h인 동안 매 평가주기 활성이며, NORMAL, FAULT, DEGRADED에서 같은 지속 기간이다.
- **F-017 17쌍 ↔ 6.3 ↔ F-031**: OFF 쌍 4개(3과 4~7)가 제외되고 나머지 17쌍이 시험된다. F-028도 같은 17쌍을 사용한다.
- **6.1 활성 규칙 ↔ 억제 규칙**: 정의가 OFF의 순위 4~7과 DEGRADED/FAULT의 순위 6을 제외하며 SRS-F-031, SSR-010, SSR-011과 일치한다.
- **SAFETY-REQ ↔ SRS**: SSR-004의 override 예외(F-007, F-030), SSR-005의 F-007 참조, SSR-010/011의 명령 미적용, SSR-013의 순위 1~3, SSR-016의 순위 4·5·7이 SRS 6.3과 일치한다. SAF는 순위 번호를 복제하지 않는다.
- **ASSUMPTIONS ↔ SRS/SAFETY**: A-01(6.3 순서), A-02(SSR-011, SSR-013, SSR-016), A-03(F-007, F-029, F-030, SSR-004, SSR-005, A-18), A-04(SSR-008~010, SSR-016), A-08(F-004, SRS 6.4), A-09(F-024), A-14(F-016, F-031, 6.3), A-15(F-025), A-16(6.1, SSR-008), A-17(F-014), A-18(F-030, F-002)의 참조가 현재 ID와 일치한다.
- **상태 체계 ↔ 상태 값**: 상태 체계 설명이 "가정(승인됨)", "가정(작성자 결정, 사용자 확인 대기)", "확인"을 정의한다. A-01~A-09, A-11~A-12, A-13~A-18, A-10에 쓰인 값이 이 정의와 일치한다.
- **편차·승인 기록 ↔ TRACE §3**: 두 표의 편차 항목과 A-ID 목록이 일치한다 (A-01~A-09 사용자 "제안안" 승인, A-13~A-18 작성자 결정 및 사용자 확인 대기, A-11 편차). 승인의 존재만 확인했으며 실제 승인 사실은 결함으로 보지 않는다.
- **TRACE ↔ SRS/SSR**: TRACE §1의 SRS 35행과 SSR 16행이 원문서와 일치한다 (ID 집합 비교 확인; 차이는 §8 이력 표의 폐기 ID 행뿐). §2 OEM 역추적에 OEM-SR 4, FR 7, NFR 2, IF 9가 모두 있다.
- **수치**: 300 ms(SSR-002), 200 ms(SSR-008), 100 ms(SSR-009), 3 km/h(SRS-L-004), 1,000주기/10 s(SRS-L-005), 100건(SRS-L-006), 0.0~300.0 km/h(SRS-L-007)가 OEM 원문과 일치한다.
